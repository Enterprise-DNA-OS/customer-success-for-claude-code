# What a screen gives you

This is an operator-run database for weekly customer retention work. Claude Code, Codex, OpenCode or Cursor reads the same commands and records. Generated HTML views and documents are read-only and printable.

A hosted customer success product adds mobile interaction, live collaboration, portals, background event collection and connected notifications. This base does not implement those. It needs an operator to import evidence and run the review. It does not send email, collect product telemetry or predict churn.

Enterprise DNA can build the screens and connections your business needs around this database. Keep the read-only files private. A shared deployment needs authenticated access, backups and an agreed operating owner.
